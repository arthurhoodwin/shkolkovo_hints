# ShkolkovoHints

Приложение для генерации подсказок к задачам Школково.
Подходит методистам и преподавателям: можно быстро получить черновые подсказки, отредактировать их и отправить обратно на платформу.

## Что умеет

- Загружает задачу по ID.
- Показывает условие и решение.
- Генерирует подсказки через Groq API.
- Дает редактировать, переставлять и удалять подсказки.
- Отправляет подсказки в админку Школково.
- Поддерживает пакетную обработку задач.

## Для кого это

- Для сотрудников/методистов, у которых есть доступ к админке Школково.
- Для пользователей, у которых есть JWT токен и Groq API key.

## Быстрый старт (для обычного пользователя)

### Вариант 1: через готовый `.exe`

1. Скачайте `ShkolkovoHints.exe` из раздела Releases.
2. Запустите файл двойным кликом.
3. В приложении укажите:
- JWT токен Школково.
- Groq API key.

### Вариант 2: запуск из исходников

1. Установите Python 3.11+.
2. Откройте папку проекта.
3. Запустите файл `запустить.bat`.

Скрипт сам создаст окружение, установит зависимости и запустит приложение.

## Первый запуск в приложении

1. Вставьте JWT токен.
2. Вставьте Groq API key.
3. Нажмите `Загрузить` после ввода ID задачи.
4. Нажмите `Сгенерировать`.
5. Проверьте и отредактируйте подсказки.
6. Нажмите `Одобрить` для отправки на платформу.

## Где взять токены

- JWT токен: из браузера в сессии админки Школково.
- Groq API key: в личном кабинете Groq.

Никому не передавайте свои токены.

## Частые проблемы

### Приложение не запускается

- Проверьте, что антивирус не блокирует файл.
- Запустите от имени обычного пользователя, не из архиватора.
- Если запуск из исходников, убедитесь, что установлен Python.

### Ошибки сети / SSL / VPN / proxy

- В настройках приложения можно отключить проверку SSL.
- Если используете proxy, укажите корректный адрес.
- При нестабильном VPN попробуйте без него.

### Не генерируются подсказки

- Проверьте правильность Groq API key.
- Проверьте, что выбранная модель доступна.
- Проверьте интернет-соединение.

### Не загружается задача по ID

- Проверьте JWT токен.
- Проверьте доступ к админке Школково.
- Убедитесь, что ID задачи существует.

## Конфиденциальность

- Приложение сохраняет локальные настройки на вашем компьютере.
- JWT и API key должны использоваться только вами.
- Не публикуйте скриншоты с токенами.

## Версии и обновления

- Актуальные версии доступны в GitHub Releases.
- Если приложение обновилось, скачайте новый `.exe` и замените старый файл.
