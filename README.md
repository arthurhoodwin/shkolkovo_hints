# ShkolkovoHints (PyQt6)

Десктоп-приложение для генерации и редактирования подсказок к задачам платформы Школково.

Приложение:
- загружает задачу и решение по ID;
- генерирует подсказки через Groq API;
- позволяет редактировать подсказки вручную;
- умеет отправлять подсказки обратно на платформу;
- поддерживает пакетную обработку задач.

## 1. Требования

- Windows 10/11
- Python 3.11+ (рекомендуется 3.12)
- Доступ в интернет
- JWT токен Школково
- Groq API key (для генерации подсказок)

## 2. Быстрый старт

### Вариант A: запуск через BAT (рекомендуется)

1. Откройте папку проекта.
2. Запустите `запустить.bat`.
3. Скрипт автоматически:
   - создаст `.venv` при первом запуске;
   - установит зависимости из `requirements.txt`;
   - запустит `main.py`.

### Вариант B: запуск вручную

```powershell
python -m venv .venv
.venv\Scripts\activate
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
python main.py
```

## 3. Сборка EXE

Используйте `build_exe.bat`.

Что делает скрипт:
1. Создает/использует `.venv`.
2. Ставит зависимости.
3. Чистит старую сборку (`build`, `dist`, `.spec`).
4. Собирает `dist\ShkolkovoHints.exe` через PyInstaller.

Результат:
- готовый файл: `dist\ShkolkovoHints.exe`

## 4. Настройки и данные

Приложение хранит локальные файлы:
- `~/.shkolkovo_v4.json` - настройки интерфейса, токены, история;
- `~/.shkolkovo_logs/` - CSV-логи обработки.

Важно:
- эти файлы пользовательские, они не входят в репозиторий (см. `.gitignore`);
- при публикации не коммитьте реальные токены.

## 5. Переменные окружения (опционально)

Можно передавать токены через переменные:

- `SHKOLKOVO_TOKEN`
- `GROQ_API_KEY`

Если переменные заданы, они подхватываются при старте приложения.

## 8. Типовые проблемы

### Ошибка SSL / VPN / proxy

В настройках приложения отключите проверку SSL или укажите корректный proxy.

### EXE не собирается

Проверьте:
- установлен ли Python (`python --version` или `py -3 --version`);
- есть ли интернет (для установки зависимостей);
- не блокирует ли антивирус файлы в `dist/`.

### Пустой ответ от модели

Проверьте:
- корректность `GROQ_API_KEY`;
- доступность выбранной модели;
- сетевые ограничения (VPN/proxy/firewall).
